# 由 V2.0.0 到 V2.5：Typed 1，然後 Systems 1

日期：2026-09-13。Core 1 仍凍結，**不准再開語法**。  
這是實作路線，不是再一則宣言。現況對照：[compare.md](compare.md)。V2.0.0：[17-v2.md](17-v2.md)。Typed／Systems 報告：[typed/REPORT.md](typed/REPORT.md)、[systems/REPORT.md](systems/REPORT.md)。

V2.0.0 兌現的是工程：GC、模組邊界、能跑的多檔 CLI。  
V2.5 兌現的是**已經寫在表面上的含義**：`once`／`Vect` 真的擋非法狀態；`--target wasm` 不再截 stdout 假裝後端。

---

## V2.5 是什麼

一個沒讀過本倉庫的人，仍用 README 寫一支多檔本地 CLI，並且：

1. `once` 資源漏關或用兩次，`h2o check` 失敗。
2. `Vect` 長度對不上，是類型錯誤，不是執行期才爆。
3. `h2o build --target wasm` 產出能在 `wasmtime` 跑的模組，stdout 與 `h2o run` 相同。

V2.5 **不是**：GHC 替代品、LLVM、pip／crates.io、Koka 級效應列、借用檢查器、證明助理。

```
V2.0.0 已綠           能養本地 CLI（D0–D4）
        │
E0  V2.1               **已綠** once 接到真實 with／檔案
        │
E1  V2.2               **已綠** Vect n a（索引在類型裡）
        │
E2  V2.3               **已綠** Wasm 不再說謊
        │
E3  V2.4               **已綠** FFI 有類型（無新語法）
        │
E4  V2.5               **已綠** 產品閘門：黃金檔 + 文件誠實 + ./test
```

每一刀有驗收指令。沒綠不准開下一刀。不准平行開「先做 LLVM」「先做 registry」「先做 HKT kind」來逃避當下那一刀。

Typed 1 在前、Systems 1 在後。原因：`once`／`total`／`Vect` 的**語法已經進編譯器**，這一刀是兌現（和 D0 comprehension 同一種刀）。真後端是新工程，放後面。13-next 寫「可分叉」——本路線**不准分叉**。

---

## 原則

1. 黃金測試是合約。行為一變，先改測試再改編譯器。
2. 一件事一種寫法。新能力必須減少特例。
3. Core 1 已寫、實作沒做的，是**兌現**，不是開新語法。
4. C 只加運行時核。編譯器仍是 H2O（BH 子集）。
5. `--native` 在 V2.5 仍是同一套 VM。文件必須繼續這麼寫。LLVM 不是本路線。
6. `]` 仍沒有註冊中心。套件＝本地目錄。
7. 類型刀若需要新語法才能寫 `Vect[2, Text]`，用已有的 `Z`／`S[_]` 當索引，**不要**為了漂亮加數字進類型語法。

---

## 現況（V2.0.0 出發點）

已綠：D0–D4、T0–T6、REPL／入門 0–10、弱固定點、日常不靠 Python。

仍是謊或半套的：

| 洞 | 今天 |
|---|---|
| `once` | **E0 已綠：** 移動語意（別名／欄位／呼叫）；`with` 綁定仿射（最多一次，離開即關）。不是借用檢查 |
| `total def` | 擋「無條件呼叫自己」；不是結構遞迴、不是任意 ADT 終止 |
| `Vect` | **E1 已綠：** `Vect[n, a]`，n 是 `Z`／`S[_]`。`vect` 只要列表字面。`vect_head` 拒空向量 |
| 效應列 | 語法在；檢查只問「有沒有寫這個標籤」。不是列推導 |
| 列紀錄 | 語法在；沒有列多型推導 |
| HKT kind | `Functor[F[_]]` 能寫；沒有 kind 檢查 |
| overlapping | 同一型兩份 impl 報錯；沒有 solver |
| `--native` | `--vm` 別名 |
| `--target wasm` | **E2 已綠：** 同一套 VM 交叉編成 WASI；要 WASI SDK（`sh compiler/wasi-sdk.sh`）與 `wasmtime` |
| FFI | **E3 已綠：** 字面 `c.abs`／`c.labs`；錯型／未知名紅。草案 [systems/ABI.md](systems/ABI.md) |
| `h2o fmt` | 只清空白 |

## E0 — V2.1：once 接到真實資源

**已完成。** 兌現 Typed 報告的線性最小切片。語法已有：`once File`、`with io.open(...) as f`。

今天：`check_once_one` 數本體裡參數名出現幾次。`g = f`、放進紀錄、傳給另一個 `once` 參數，都算錯或漏算。

| 做 | 驗收 |
|---|---|
| 恰好一次 | `once` 參數用兩次＝`h2o check` 紅，訊息點名 |
| 漏關 | `once` 參數沒用到＝紅，「漏關」 |
| `with` | `with io.open(path) as f:` 離開作用域即關；`f` 是 `once` |
| 別名 | `g = f` 之後再用 `f` 或再用 `g`＝紅（別名算用掉） |
| 欄位 | `{h: f}` 算用掉；之後再碰 `f`＝紅 |

測資進 `./test`。`examples/linear.h2o` 仍綠。舊黃金檔不漂。

**不做：** 借用檢查器、lifetime 參數、仿射以外的變體、分代／唯一引用計數、把 `once` 接到 GC。不是 Rust。

閘門：

```
./h2o check tests/cases/once_unused.h2o    # 已紅，保持
./h2o check tests/cases/once_alias.h2o     # 新：別名再用＝紅
./test
```

沒過 E0，不准談 `Vect n`。

## E1 — V2.2：Vect n a（索引在類型裡）

**已完成。** 兌現 Typed 報告的索引向量穩定子集。不開新語法。索引是類型 `Z` 與 `S[_]`（已能寫 `List[A]`、`TApp`）。

今天：`type.h2o` 裡 `vect : List[a] -> Vect[a]`，`vect_len` 回 `Int`。`examples/vect.h2o` 用 `if vect_len(v) == 2` 證明長度——那是執行期。

| 做 | 驗收 |
|---|---|
| 種類 | `Vect[n, a]`。`vect(["a", "b"])` 的類型是 `Vect[S[S[Z]], Text]` |
| 構造 | `vect_cons(x, v)`：`a -> Vect[n, a] -> Vect[S[n], a]` |
| 取頭 | `vect_head` 只要 `Vect[S[n], a]`；空向量是類型錯誤 |
| 對不上 | `vect_cons` 接到錯誤 `n`、或兩個 Vect 長度當同一型用＝`h2o check` 紅 |

**不做：** 完整依賴類型、可視 `forall`、類型裡做任意算術、證明助理、`Vect[2, Text]` 這種數字進類型語法（那是新語法）。教學可以說「長度 2」，寫出來仍是 `S[S[Z]]`。

閘門：

```
./h2o check examples/vect.h2o
./h2o check tests/cases/vect_empty_head.h2o   # 紅
./test
```

`total def` 維持現況（無條件自呼叫失敗）。結構遞迴不是本刀。沒過 E1，不准談 Wasm。

## E2 — V2.3：Wasm 不再說謊

**已完成。** 同一套 `rt.c` + bytecode，`compiler/wasi-cc.sh` 用 WASI SDK 編成模組。`wasmtime` 跑它。不是截 stdout 的假 `.wat`。

做：同一套 `rt.c` + 同一份 bytecode 映像，用 `clang --target=wasm32-wasi`（或倉庫寫死的 WASI SDK）編成模組。`wasmtime` 跑它，stdout 與 `h2o run` 相同。

| 做 | 驗收 |
|---|---|
| 真模組 | `h2o build --target wasm examples/core0_hello.h2o -o /tmp/hello.wasm` |
| 能跑 | `wasmtime /tmp/hello.wasm` 印 `active: Ada, Edsger` |
| 黃金 CLI | 同一條對 `examples/wc` 成立（讀檔用 WASI） |
| 不再假裝 | 產出物裡**沒有**把 `println` 截下來當常數字串的假 `_start` |

工具鏈寫進 README。沒有 `wasmtime`／wasi 目標＝這一刀沒綠，**不准**用「先截輸出」當綠。`./test` 的 `wasm` 項改成跑模組，不是對假 `.wat` 做字串比對。

**不做：** 把 H2O ISA 譯成 Wasm 指令、LLVM、`--native` 變機器碼、JS 宿主、瀏覽器 DOM。

閘門：

```
./h2o build --target wasm examples/core0_hello.h2o -o /tmp/hello.wasm
wasmtime /tmp/hello.wasm
./test
```

## E3 — V2.4：FFI 有類型

**已完成。** `prim.ffi_call` 認字面庫名／符號。錯型與未知名是 `h2o check` 紅。ABI 草案：[systems/ABI.md](systems/ABI.md)。

不准新語法。包裝仍是普通 `def`：

```
def c_abs(x: Int) -> Int:
    prim.ffi_call("c", "abs", x)
```

| 做 | 驗收 |
|---|---|
| 類型 | `prim.ffi_call("c", "abs", "no")` 是類型錯誤，不是執行期爛掉 |
| 未知符號 | 不在表裡的名字＝`h2o check` 紅 |
| ABI 草案 | [systems/ABI.md](systems/ABI.md)：`Val` 標籤、整數／文字怎麼過 C 邊界。草案，不是工業穩定 |
| 舊演示 | `examples/ffi.h2o` 仍綠；改走有類型的包裝 |

**不做：** 穩定 ABI 承諾、任意 C struct、callback 進 H2O、把編譯器改用 FFI 重寫。

閘門：

```
./h2o check tests/cases/ffi_abs_text.h2o    # 紅
./test
```

## 明確不進 V2.5

| 不做 | 放到 |
|---|---|
| LLVM、真機器碼、`--native` 改義 | V3 Systems 或永不；本路線 `--native` 繼續誠實 |
| Koka 級列推導、overlapping solver、HKT kind 推滿 | **Core 1.1**，V2.5 之後另開路線。不是 V2.1 |
| 套件註冊中心、遠端解算 | 永不在本路線（Core 1 套件＝目錄） |
| 借用檢查器、所有權學科 | Typed 之上，見 [06-optional.md](06-optional.md) |
| 完整依賴類型、證明助理 | Typed 更後 |
| `h2o fmt` AST 重印成 gofmt | 加分，不是閘門 |
| LSP、tab 補全、`ans` | 編輯器 |
| 用完整表面語法重寫編譯器 | 不當閘門（編譯器仍 BH） |
| GHC 相容、方法鏈、`$`、pragma | 永不 |
| 分代／壓縮／並行 GC | 執行期研究，不是閘門 |

[17-v2.md](17-v2.md) 曾把「Koka 列／HKT kind」寫成「V2.1 類型刀」。那句的意思是**不進 V2.0.0**，不是指定下一刀。下一刀是 E0（`once`）。列推導會把 Typed 1 拖死，和它當年會把 T0–T4 拖死是同一件事。

## 和三門語言（V2.5 過完之後）

| | V2.5 仍比不過 | V2.5 追平的窄帶 |
|---|---|---|
| GHC | 生態、優化、惰性、工業 HM | 嚴格小工具；資源漏關能擋一點 |
| Python | PyPI、電池 | 本機 CLI；類型擋錯；WASI 能跑同一支 |
| Rust | 借用、LLVM、cargo | 不相近；`once` 不是借用檢查 |

過完 V2.5，H2O 是 **能養本地工具、能把資源／長度寫進類型、能在 WASI 跑同一套 VM 的嚴格腳本語言**。仍不是工業編譯器。
