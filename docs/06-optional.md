# 可做成選配層、不必進核心的項目

這些有價值，但塞進核心會重蹈「擴充爆炸」。選配的意思是：穩定介面、自願開啟、不衍生不相容方言。

| 能力 | 建議位置 | 理由 |
|---|---|---|
| 精細型別（Liquid Haskell 風格） | 選配檢查器 | 不變式很有用，但不該讓核心種類系統再脹一倍 |
| 度量單位 | 函式庫＋種類 | 領域特定，不需新計算模型 |
| 完整證明助理模式 | 選配後端／層 | 與 Lean／Rocq 分工，H2O 仍應先是程式語言 |
| 物件能力／權限 | 效應列的一種解釋 | 可編碼，不必新原語 |
| 所有權＋借用 | 線性型別之上的學科 | 先把線性做對 |
| 內容定址的函數身分 | 編譯／套件層實驗 | Unison 已示範價值；不是 Haskell 思想的定義特徵 |

選配層的規則：

- 關掉它，Core 程式的含義不變。
- 開啟它，不需要再列一串 pragma。
- 錯誤訊息仍用程式設計師詞彙，不洩漏檢查器內部。
