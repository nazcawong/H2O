# H2O Typed — 語言報告（草案 0）

自願加註解，不是另一個方言。關掉這些註解，Core 含義不變。推導會變弱——這是代價，診斷必須跟上。

## 線性／仿射

- 線性：恰好用一次。
- 仿射：最多用一次。
- 用途：檔案控制代碼、緩衝區、唯一所有權、協議狀態機。
- 作用域型資源是線性處理器，不是慣例。
- 不是 Rust 借用檢查器。所有權＋借用若要做，是這層之上的學科。

## 依賴子集（不是 Agda）

必備：

- 索引族
- 可視 `forall`
- 項可提升為類型的穩定子集
- 依賴模式比對

不要：

- 用三十個擴充假裝已經有依賴類型
- 預設全開（會失去「多數程式少寫註解」）

## 總性

模組或函數層宣告：此定義必須涵蓋所有情況且終止。

不強迫全語言總性，以免綁死 I/O 與協作。

## 明確不在 Typed

完整證明助理模式、精細型別（Liquid 風格）——見選配層。
