# 語言分層

用三層取代「GHC2024 + 二十個 pragma」。一層有一份穩定報告。往上走是自願加註解，不是打開另一個不相容方言。

## Core

純、嚴格預設、ADT、模式比對、HM + HKT、類型類、效應列、列紀錄、安全 Prelude。

表面：Python 式縮排與 `and`／`or`／`if cond:`；呼叫 `f(x, y)`；多步資料只用 `|>`。`.` 不是方法。見 [10-syntax.md](10-syntax.md)、[11-readability.md](11-readability.md)。

這是預設語言。多數應用、多數函式庫停在這裡。

包含：

- 純度；效果出現在類型裡
- 嚴格求值預設；惰性串流／無限結構為明確型別
- `Text`、`ByteString`；`[Char]` 不是文字
- 匿名紀錄、列多型、開放和型別、`.` 存取、無頂層選擇器污染
- 效應列與處理器；`IO` 是處理器之一
- 結構化並發作為效應（取消、遮罩、作用域）
- 安全 Prelude：`NonEmpty`、`Maybe`／`Either`；部分函數不在預設範圍
- 類型類；`Functor` → `Applicative` → `Monad`；定律可檢查
- 實例與型別／類別同模組；orphan 顯式

不包含：線性註解、依賴量化、總性強制、FFI 細節。

## Typed

線性、索引／依賴子集、總性註解、可視量化。

自願加註解。推導會變弱——誠實接受，診斷必須跟上。

包含：

- 線性／仿射型別作資源系統
- 索引族、可視 `forall`、可提升項的穩定子集、依賴模式比對
- 模組或函數層的總性宣告
- 不包含完整證明助理體驗（那是選配後端）

## Systems

原生表示、未提升型別、FFI、線性緩衝、後端相關原語。

這層是執行期契約，不是第二套表面語言。

包含：

- 穩定 ABI；原生與 WASM 後端
- 未提升／未boxed 表示
- FFI
- 與線性型別對齊的緩衝區與外來資源

## 報告節奏

- 每層一份短報告，有版本（例如 Core 1、Typed 1）。
- 新能力先問：它減少擴充嗎？它能進現有層而不裂方言嗎？
- 不開 `LANGUAGE` 開關清單。需要選擇時，選的是層與版本，不是檔案頭二十行 pragma。
