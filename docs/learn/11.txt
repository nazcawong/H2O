Lesson 11  once, Vect, Wasm

once: the parameter is used exactly once (a move). After g = f you must not touch f.
{h: f} also uses it up. with io.open(path) as f: closes on leave; f at most once inside.
Not a borrow checker, no lifetimes.

Vect: length lives in the type. Indices are Z and S[_], not Vect[2, Text].

  vect(["a", "b"])           type Vect[S[S[Z]], Text]
  vect_cons(x, v)            Vect[n, a] -> Vect[S[n], a]
  vect_head needs non-empty; vect([]) is a type error
  vect takes list literals only

Wasm: h2o build --target wasm compiles the same VM to a WASI module.

  ./h2o build --target wasm examples/count -o /tmp/count.wasm
  wasmtime --dir=. /tmp/count.wasm run examples/count examples/count/sample.txt

Not LLVM, not a translation of H2O into Wasm instructions. --native emits C functions then cc: machine code; --vm is the interpreter.
Packages stay local directories; no registry. h2o vendor <git-url> [name] copies a git tree into vendor/<name>/.

Golden tool (once + Vect; native / run / wasm same output):

  ./h2o run examples/count examples/count/sample.txt
  ./h2o build --native examples/count -o /tmp/count
  /tmp/count run examples/count examples/count/sample.txt

Should print count 3.

Exercises:

  1) run examples/count, confirm count 3
  2) :t vect(["a", "b"])
  3) use an once parameter twice and read that it cannot be used twice
