Lesson 5  match and Maybe

No null. A missing value is Maybe: Some(x) or None.
match must cover every constructor (or use _).

  xs = [10, 20]
  match xs[0]:
      case Some(n):
          n
      case None:
          0

Omitting case None is a type error: match does not cover None.
List destructuring:

  match [1, 2, 3]:
      case []:
          0
      case [n, *rest]:
          n

Exercises:

  1) index [] at [0], match Some / None, print "empty" or the number
  2) write only case Some on purpose and read that None is not covered
