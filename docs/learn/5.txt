第 5 課  match 與 Maybe
EN: Lesson 5  match and Maybe

沒有 null。可能沒有值就用 Maybe：Some(x) 或 None。
match 必須寫完所有建構子（或用 _）。

  xs = [10, 20]
  match xs[0]:
      case Some(n):
          n
      case None:
          0

少寫 case None 是類型錯誤：match 沒有涵蓋 None。
列表解構：

  match [1, 2, 3]:
      case []:
          0
      case [n, *rest]:
          n

練習：

  1) 對 [] 取 [0]，match Some / None，印 "empty" 或數字
  2) 故意只寫 case Some，讀「沒有涵蓋 None」
