Lesson 7  effects {IO}

A pure function cannot print on the side. println needs {IO}.
Unannotated main implies {IO}. REPL evaluation also carries {IO}.
Calling a {IO} function requires {IO} on the caller too.

  def greet(n: Text) -> {IO} ():
      println(cat("hi ", n))

  def add(x, y):
      x + y

add has no {IO}, so it cannot println.
Read a file with io.read_file("path"), also {IO}.
CLI: argv(), write_out, eprint (stderr), exit(n). Use write_out for raw text; println quotes Text.
Long-running programs rely on GC. Do not assume collection only happens at exit; the REPL collects after each evaluation.
