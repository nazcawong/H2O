Lesson 3  functions

  def add(x, y):
      x + y

  add(1, 2)

The last expression is the return value. return is not the everyday spelling.
Annotations are optional; the checker infers:

  def add(x: Int, y: Int) -> Int:
      x + y

Several parameters use commas. No automatic curry.
Anonymous functions:

  fn(x): x + 1

Exercises:

  1) define double(n) returning n * 2, then double(21)
  2) :t double   should mention Int
  3) try double("a") on purpose and read the error
