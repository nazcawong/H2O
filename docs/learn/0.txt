H2O tutorial (help?> mode)

Meaning like Haskell (purity, types, ADTs); written like pseudocode.
One way to write a thing. No method chaining, no $, no do.

Table of contents — type a number at help?> (or ? 1 at h2o>):

  0  this index
  1  REPL and the first expression
  2  conditionals: if / and / or / not
  3  functions (def)
  4  lists and pipelines |>
  5  match and Maybe
  6  records (fields use .)
  7  effects {IO}
  8  exercises
  9  trait and impl
  10 modules, directory packages, long-running programs
  11 once, Vect, Wasm
  modes  the four REPL prompts
  trait / impl / Eq / Functor also open lesson 9
  pkg / module / gc open lesson 10
  once / Vect / wasm / native open lesson 11

Other queries (for example map) print a type, not a lesson.
A blank line leaves help and returns to h2o> for exercises.
Lessons live in docs/learn; start the REPL from the H2O repo root.
