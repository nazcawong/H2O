Lesson 4  lists and pipelines

Lists are strict and finite. Multi-step transforms use only |>.
. is not a method: you cannot write [1, 2].map(...)

  [1, 2, 3]
  map([1, 2, 3], fn(x): x + 1)
  filter([1, 2, 3], fn(x): x > 1)
  join(["Ada", "Edsger"], ", ")
  [x + 1 for x in [1, 2, 3] if x > 1]

A pipeline feeds the left-hand value as the next function’s first argument.
_ is a hole: that element’s field or operation.

  xs = [1, 2, 3]
  xs
      |> map(_ + 1)
      |> filter(_ > 2)

One short step: a comprehension. Several steps: only |>. Two problems, not two styles.

Indexing xs[i] has type Maybe; you do not get the element raw.

Exercises:

  1) divide each of [10, 20, 30] by 10
  2) keep values > 1 from [1, 2, 3]
  3) use a comprehension to get [2, 3] (from [1, 2, 3], keep > 1)
  4) try [1].map(fn(x): x) and see method chaining rejected
