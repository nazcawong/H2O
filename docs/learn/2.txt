Lesson 2  conditionals

and / or / not are English words, not && || !.
No parentheses around the condition. Blocks are 4 spaces.

  if 3 > 1 and 2 != 0:
      "yes"
  else:
      "no"

Rejected forms:

  if (x):          no parentheses on the condition
  if x && y:       no &&

elif follows if. There is no switch.

Exercises:

  1) an if: n = 4; if n > 0 print "pos", else "no"
     (n = 4, then if n > 0: ...  remember a blank line ends the block)
  2) try not True
