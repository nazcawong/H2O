Lesson 1  REPL and the first expression

The h2o> prompt evaluates. Press Enter when done.
Indented blocks (def / if / match) end with a blank line.

Numbers, text, booleans:

  1 + 2
  "Ada"
  True
  :t 1 + 2          (or ? 1 + 2)

Calls always use parentheses: f(x, y). No juxtaposition f x.
Join text with cat, not +:

  cat("hello ", "Ada")

Exercises (blank line back to h2o>, then type):

  1) compute 6 * 7
  2) use cat to make hello Ada
  3) :t cat("a", "b")  should show Text
