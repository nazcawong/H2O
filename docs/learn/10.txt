Lesson 10  modules, directory packages, long-running programs

pub: once a file has any pub, unmarked names are not visible from other files (not exported).
A single-file script with no pub at all still exposes every top-level name.

  import greet          try greet.h2o first, else greet/mod.h2o
  from user import active_names
  :load path/           loads path/mod.h2o
  ./h2o run dir/        loads dir/main.h2o

Packages are local directories. No remote registry. h2o vendor <git-url> [name] copies a git tree into vendor/<name>/, still a directory. ] only explains this.

Golden tool (30-minute path):

  ./h2o run examples/count examples/count/sample.txt

Long-running programs rely on GC (mark–sweep). The REPL collects after each evaluation.
h2o build --native emits C functions then cc: machine code (still tagged Val).
--vm is the interpreter image. --target wasm compiles the same VM to a WASI module, not an instruction translation.
