第 10 課  模組、目錄套件、長跑
EN: Lesson 10  modules, directory packages, long-running programs

pub：檔裡一旦出現 pub，沒標的名字別的檔不能呼叫（「未匯出」）。
沒有任何 pub 的單檔腳本，頂層名字仍全部可見。

  import greet          先試 greet.h2o，否則 greet/mod.h2o
  from user import active_names
  :load path/           載入 path/mod.h2o
  ./h2o run dir/        載入 dir/main.h2o

套件＝本地目錄。沒有遠端 registry。`h2o vendor <git-url> [name]` 把 git 樹拷進 `vendor/<name>/`，之後仍是目錄。`]` 只說明這件事。

黃金工具（30 分鐘路徑）：

  ./h2o run examples/count examples/count/sample.txt

應印 count 3。`once`／`Vect`／Wasm 見第 11 課。沒給檔則 stderr 含 usage、exit 2。

長跑靠 GC（標記－清除）。REPL 每一輪求值結束會收。
`h2o build --native` 發 C 函數再 cc，是機器碼（仍 tagged Val）。
`--vm` 是解釋器映像。`--target wasm` 把同一套 VM 編成 WASI 模組，不是指令翻譯。

  3) 對沒標 pub 的名字從另一檔呼叫，讀「未匯出」
