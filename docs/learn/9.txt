Lesson 9  trait and impl

Type classes: constraints go on parameters. Int / Bool / Text / lists have Eq built in.
A custom ADT has no Eq until you write impl.

impl Functor[Int] is an error: Int is not F[_]. Two impls for one type is an error; no solver.

  def contains[A: Eq](xs: List[A], x: A) -> Bool:
      any(xs, fn(y): y == x)

  contains([1, 2], 1)

type Color then contains([Red], Blue) is a type error: Color has no Eq.

== is still same-type comparison. Without [A: Eq], Red == Blue can pass.

Trait methods pick an impl from the first argument’s type constructor (blank line ends an indent block):

  trait Functor[F[_]]:
      def map[A, B](fa: F[A], f: A -> B) -> F[B]

  impl Functor[List]:
      def map(xs, f):
          map(xs, f)

  impl Functor[Maybe]:
      def map(mx, f):
          match mx:
              case None:
                  None
              case Some(x):
                  Some(f(x))

  Functor.map([1, 2], fn(x): x + 1)
  Functor.map(Some(1), fn(x): x + 1)
  Functor.map(1, fn(x): x)     error: Int has no Functor

You cannot write two impls for the same type. List example: :load examples/traits.h2o
(the file has def main; after :load, use the names in that file.)
