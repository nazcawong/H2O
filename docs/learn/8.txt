Lesson 8  exercises

Do each at h2o>. Stuck? ? 1 … ? 9.

A. Arithmetic
   Write is_even(n): True when n is divisible by 2. Try is_even(4), is_even(5).

B. Lists
   Join ["Ada", "Grace", "Edsger"] into one string, comma-space separated.
   (join)

C. Pipeline
   xs = [1, 2, 3, 4, 5]
   keep the evens, then * 10 each. Use |>.

D. Maybe
   Define first(xs): return xs[0] as that Maybe; do not unwrap it yourself.
   Then match first([7, 8]) and print 7.

E. Records
   A list of three people (name, active). Print the names where active is True, comma-separated.
   See examples/core0_hello.h2o, or :load examples/core0_hello.h2o
   (the file needs def main; after :load, use the names in that file.)

F. Effects
   Write def boom() -> Int: println("no")
   confirm it is rejected; then write a correct {IO} version.

G. trait
   Write Functor[Maybe] map so Functor.map(Some(4), fn(x): x + 1)
   yields Some(5). Stuck? ? 9.

When done, ? 0 returns to the index. Full programs: ./h2o run file.h2o.
