# 優先序與階段

實作細節與版本閘門以倉庫根目錄 **[ROADMAP.md](../ROADMAP.md)** 為準。本檔只保留「為什麼這四件、階段在想什麼」。

## 若只能做四件（對齊 V1.0）

1. **效應系統入核心** — v0.5，V1.0 不可缺  
2. **列紀錄／開放和型別** — v0.4，V1.0 不可缺  
3. **嚴格預設 + 安全文字／Prelude** — v0.1–v0.2，V1.0 不可缺  
4. **線性資源 + 實用依賴類型** — 線性／總性在 v0.9（可延後發 1.0）；完整依賴類型在 V1.1+

其餘（內容定址、精細型別、完整證明、自舉）不是 V1.0 的定義特徵。
